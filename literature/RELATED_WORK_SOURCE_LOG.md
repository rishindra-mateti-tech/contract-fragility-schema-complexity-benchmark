## 1. Verification Protocol

Every entry in this log has been verified against at least one immutable primary source:
1. **Peer-reviewed Conference Proceedings / Official Archive** (ACM, IEEE, ACL Anthology, NeurIPS, ICLR, ICML, arXiv).
2. **Official Code Repository** (GitHub organization / author repository).
3. **Official Dataset Release** (Hugging Face / Zenodo / Institutional portal).

Verification methods include direct web search against archival registries, DOI resolution, and inspection of repository trees for schema formats and execution runners.

## 2. Citation Verification Records

### 1. Gorilla / APIBench (`patil2023gorilla`)
- **Title:** Gorilla: Large Language Model Connected with Massive APIs
- **Authors:** Shishir G. Patil, Tianjun Zhang, Xin Wang, Joseph E. Gonzalez
- **Venue:** Advances in Neural Information Processing Systems (NeurIPS 2024), Vol. 37; arXiv:2305.15334
- **Primary Paper URL:** https://arxiv.org/abs/2305.15334
- **Official Code Repository:** https://github.com/ShishirPatil/gorilla
- **Official Dataset Release:** Included in Gorilla repository (`data/apibench/`) and Hugging Face (`gorilla-llm/apibench`)
- **Verification Method:** Web search against arXiv API and NeurIPS 2024 conference proceedings; GitHub repository tree inspection.
- **Artifact Nature:** API signatures scraped from TorchHub, HuggingFace, and TensorHub; primarily single-layer function calls with flat keyword arguments.

### 2. ToolLLM / ToolBench (`qin2024toolllm`)
- **Title:** ToolLLM: Facilitating Large Language Models to Master 16000+ Real-world APIs
- **Authors:** Yujia Qin, Shihao Liang, Yining Ye, et al.
- **Venue:** International Conference on Learning Representations (ICLR 2024, Spotlight); arXiv:2307.16789
- **Primary Paper URL:** https://arxiv.org/abs/2307.16789
- **Official Code Repository:** https://github.com/OpenBMB/ToolBench
- **Official Dataset Release:** https://github.com/OpenBMB/ToolBench#dataset and Hugging Face (`openbmb/ToolBench`)
- **Verification Method:** ICLR 2024 proceedings indexing; OpenBMB repository confirmation.
- **Artifact Nature:** 16,464 REST APIs crawled from RapidAPI Hub. RapidAPI schemas are largely flat key-value pairs; query and body parameters are flattened; response bodies often ungrounded.

### 3. ToolAlpaca (`tang2023toolalpaca`)
- **Title:** ToolAlpaca: Generalized Tool Learning for Language Models with 3000 Simulated Cases
- **Authors:** Qiaoyu Tang, Ziliang Deng, Hongyu Lin, Xianpei Han, Qiao Liang, Boxi Cao, Le Sun
- **Venue:** arXiv preprint arXiv:2306.05301 (2023)
- **Primary Paper URL:** https://arxiv.org/abs/2306.05301
- **Official Code Repository:** https://github.com/tangqiaoyu/ToolAlpaca
- **Official Dataset Release:** Hosted within GitHub repo and Hugging Face (`tangqiaoyu/ToolAlpaca`)
- **Verification Method:** arXiv registry lookup; GitHub release verification.
- **Artifact Nature:** Fully synthetic tool schemas generated by self-instruct simulation across 400+ tools; flat schemas with generic parameter descriptions.

### 4. Berkeley Function Calling Leaderboard (BFCL) (`yan2024bfcl`)
- **Title:** The Berkeley Function Calling Leaderboard (BFCL): From Tool Use to Agentic Evaluation of Large Language Models
- **Authors:** Fanjia Yan, Huanzhi Mao, Charlie Cheng-Jie Ji, Tianjun Zhang, Shishir G. Patil, Ion Stoica, Joseph E. Gonzalez
- **Venue:** ICML 2024 Workshop on Foundation Models in the Wild; Live Leaderboard
- **Primary Paper URL:** https://gorilla.cs.berkeley.edu/blogs/8_berkeley_function_calling_leaderboard.html

- **Official Dataset Release:** https://huggingface.co/datasets/gorilla-llm/Berkeley-Function-Calling-Leaderboard
- **Verification Method:** Gorilla project site; ICML 2024 workshop paper indexing; live dashboard tracking.
- **Artifact Nature:** Curated Python/Java/REST function calls evaluated via Abstract Syntax Tree (AST) matching. Nesting depth is primarily 1; does not evaluate schema contract mutation resilience.

- **Authors:** Brandon T. Willard, Rémi Louf
- **Venue:** arXiv preprint arXiv:2307.09702 (2023)

### 10. FOFO: Follow the Format (`xia2024fofo`)

- **Primary Paper URL:** https://arxiv.org/abs/2402.18667
- **Verification Method:** arXiv registry check.
- **Artifact Nature:** Measures adherence to generic formatting instructions (JSON, YAML, XML, markdown tables). Does not benchmark tool calling, OpenAPI parameters, or schema mutation fragility.

### 11. StructEval (`tang2024structeval`)
- **Title:** StructEval: Deep Exploration of Format-Following Capabilities of Large Language Models
- **Authors:** Chen Tang, Zhi Huang, Xiaotian Liu, Min Yang, Yujun Shen
- **Venue:** arXiv preprint arXiv:2410.08815 (2024)
- **Primary Paper URL:** https://arxiv.org/abs/2410.08815
- **Verification Method:** arXiv registry check.
- **Artifact Nature:** Evaluates 18 structured formats across 44 task types. Provides general format metrics but does not test real-world API contract boundaries, path/query/body partitioning, or semantic mutation drift.

### 12. Benchmark Contamination & Freshness (`golchin2024timetravel`, `white2024livebench`, `sainz2024nlpeval`)
- **Titles:**
  - *Time Travel in LLMs: Tracing Data Contamination in Large Language Models* (Golchin & Surdeanu, ICLR 2024; arXiv:2308.08493)
  - *LiveBench: A Challenging, Contamination-Free LLM Benchmark* (White et al., arXiv:2406.12039, 2024)
  - *NLP Evaluation in Trouble: On the Need to Verify Data Contamination for Language Models* (Sainz et al., EACL 2024; arXiv:2311.08298)
- **Verification Methods:** ICLR 2024, EACL 2024 ACL Anthology proceedings, arXiv registries.
- **Artifact Nature:** Foundational literature establishing that static benchmarks published openly on GitHub/HuggingFace are rapidly ingested into pre-training corpora, necessitating cryptographic immutability, programmatic mutations, and controlled provenance tracking.
